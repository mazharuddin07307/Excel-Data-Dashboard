# Ali Store Annual Sales Dashboard (Excel)

## Project Overview
An interactive Excel dashboard analyzing the annual sales performance of Ali Store (2026 Annual Report). The dashboard consolidates order data, customer demographics, and sales channel performance into a single-page interactive view using PivotTables, PivotCharts, and Slicers.

## Data
- **Source:** Store's e-commerce sales records (order-level data including date, channel, category, customer age/gender, and revenue)
- **File:** `Store Excel Data.xlsx`
- **Dashboard File:** `Store Pivot Dashboard.xlsx`

## Dashboard Features

### Key Visualizations
- **Order vs Sale (Monthly Trend):** Bar chart tracking order volume against sales value across all 12 months
- **Sales: Men vs Women:** Pie chart showing gender-wise sales split (Women 64%, Men 36%)
- **Order Status Breakdown:** Pie chart showing Delivered (92%), Refunded (2%), Returned (3%), and Cancelled (3%) orders — useful for tracking fulfillment health
- **Top 5 States by Sales:** Horizontal bar chart ranking top-performing states (Maharashtra, Karnataka, Uttar Pradesh, Telangana, Tamil Nadu)
- **Order: Age vs Gender:** Comparison of order volume across Adult, Senior, and Teenager age groups
- **Orders by Channel:** Pie chart showing sales distribution across platforms (Amazon 35%, Myntra 23%, Flipkart 22%, Meesho 5%, Ajio 6%, Nalli 5%, Others 4%)

### Interactive Filters (Slicers)
- **Month:** Filter data by any month (Jan–Dec)
- **Channel:** Filter by sales platform (Myntra, Meesho, Nalli, Others)
- **Category:** Filter by product category (Blouse, Bottom, Ethnic Wear, Kurta, Saree)

## Key Insights
- Women customers drive the majority of sales (64%)
- Delivery success rate is strong at 92%, with combined returns/refunds/cancellations under 8%
- Amazon and Myntra are the top-performing sales channels
- Maharashtra and Karnataka lead in state-wise sales performance

## Excel Skills Demonstrated
- PivotTables & PivotCharts
- Data Slicers for interactive filtering
- Multiple chart types (bar, pie, horizontal bar) for varied data storytelling
- Dashboard layout design and formatting
- KPI-driven reporting for business decision-making
